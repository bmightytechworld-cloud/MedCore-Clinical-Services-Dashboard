## MedCore Clinical Services Dashboard

## Client Request
US medical clinic managing 4 departments needed 
3 disconnected sheets cleaned, merged and automated 
with a full performance dashboard showing department 
activity, revenue and outstanding patient balances.

## Problems Found
- Duplicate patient visit records
- Inconsistent department names throughout
- Inconsistent visit status across all rows
- Mixed date formats across all rows
- Missing copay amounts on multiple visits
- Missing patient balance calculations
- Missing payment status on multiple records
- Doctor details in separate disconnected sheet
- Billing records in separate disconnected sheet

## What I Fixed
- Removed all duplicate visit records
- Standardized all department and status names
- Unified all date formats
- Handled all missing copay values
- Calculated missing patient balances automatically
- Merged doctor database using Doctor ID
- Merged billing records using Visit ID
- Built pivot view showing revenue by department
  per visit type
- Built input sheet with dropdown validation
- Built summary dashboard with key metrics
  and charts

## Deliverables
- Sheet 1 — Raw Patient Visits
- Sheet 2 — Raw Doctor Database
- Sheet 3 — Raw Billing Records
- Sheet 4 — Master Clinical Table
- Sheet 5 — Pivot View
- Sheet 6 — Input Sheet
- Sheet 7 — Summary Dashboard
